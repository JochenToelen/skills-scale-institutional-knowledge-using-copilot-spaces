# OctoAcme RACI Matrix

RACI defines who is **Responsible** (does the work), **Accountable** (final owner), **Consulted** (provides input), and **Informed** (kept updated) for each project phase.

| Project Phase | PM | PdM | Developer | QA | Tech Lead | UX/Design Lead | Scrum Master | BA | Security Officer | Sponsor |
|---|---|---|---|---|---|---|---|---|---|---|
| Initiation | R | A | I | I | C | C | I | C | C | C |
| Planning | A | R | C | C | C | C | R | R | C | I |
| Execution | A | C | R | R | A | C | R | C | C | I |
| Release | A | C | R | R | A | C | C | I | R | I |
| Retrospective | A | C | R | R | C | C | R | C | C | I |
